# 💫 About Me:
Soy estudiante de Ingeniería de Sistemas, apasionado por la tecnología, el desarrollo de software y la creación de soluciones que resuelvan problemas reales. Tengo experiencia desarrollando aplicaciones web y móviles, trabajando con tecnologías como JavaScript, Node.js, Express, React, React Native, Python, SQL y bases de datos como MySQL y Supabase. He participado en proyectos como Cochabamba Reporta, orientado a la gestión de reportes ciudadanos, y un sistema web para una concesionaria BMW, aplicando buenas prácticas de programación, organización del código y control de versiones con Git y GitHub. También estoy explorando la computación en la nube con AWS y sus servicios. Me caracterizo por ser una persona responsable, comprometida, colaborativa y con muchas ganas de aprender, mejorar mis habilidades y convertir ideas en soluciones tecnológicas útiles e innovadoras.
